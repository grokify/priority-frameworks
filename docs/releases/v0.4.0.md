# Release Notes v0.4.0

This release adds a distinct, opt-in short display form to `Level`, and a few missing shorthand aliases for `Severity`. No breaking changes.

## Highlights

- `Level.Abbreviation`: a short display form (e.g. `"CRIT"`) alongside the existing `Name` (e.g. `"Critical"`) — pick whichever fits a given call site, including using both in different places within the same application
- `Framework.AbbreviationFor(idOrName)` returns the abbreviation with a fallback to `Name` when a level has none (e.g. Priority's `"P0"` is already minimal)
- `Severity` gains `CRIT`/`crit`, `MED`/`med`, and lowercase `info` as accepted parse aliases

## Added

### `Level.Abbreviation`

`Name` already served as the canonical, title-cased display form. `Abbreviation` adds a short form alongside it, not instead of it:

```go
level := pf.Severity().Parse("critical")
fmt.Println(level.Name)         // "Critical"
fmt.Println(level.Abbreviation) // "CRIT"

// Or via the convenience accessor, which falls back to Name when a level
// has no distinct abbreviation:
fmt.Println(pf.Priority().AbbreviationFor("p0")) // "P0" (Name, no separate Abbreviation)
```

`Abbreviation` is always upper-case, as the one canonical value to build from — a caller wanting a different case applies that transform itself rather than the library storing every case variant. It is populated for Severity (`CRIT`/`HIGH`/`MED`/`LOW`/`INFO`), MoSCoW (`M`/`S`/`C`/`W`), and General (`REQ`/`REC`/`OPT`/`AVD`); left empty for Priority, IETF, and IETF Prohibitions, whose `Name` is already minimal.

This is a separate concern from `Aliases`, which only affects parsing (`Parse`/`IndexOf`) — adding an alias never changes what `Name`/`Abbreviation` emit for a level.

### New Severity aliases

`Severity` previously had no shorthand alias for Critical (`"Crit"` only, mixed case) or Medium (`"Med"` only), and no lowercase `"info"` for Informational. Now `CRIT`, `crit`, `MED`, `med`, and `info` all parse correctly, matching the common `CRIT`/`HIGH`/`MED`/`LOW`/`INFO` shorthand convention.
